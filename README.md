# Al-Noor Tile Studio

A luxury ANTIGRAVITY 3D tile showroom for a UAE building materials company.

## Prerequisites
- **Node.js** (v18+ recommended)
- **npm** (comes with Node.js)

## Setup Instructions
Since you currently do not have Node.js installed in this environment, please follow these steps once Node.js is installed:

1. **Install Dependencies:**
   Open a terminal in this directory (`c:\Users\rizvi\Shurq agent`) and run:
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **View the Application:**
   Open the URL provided in your terminal (usually `http://localhost:5173`) in your web browser.

## Current Implementation Status
- **App Shell & Layout**: Fully implemented with luxury styling.
- **Three.js Scene Setup**: Includes HDR-like lighting, postprocessing bloom, and stars.
- **Antigravity Tile Galaxy**: 40 tiles generated procedurally with PBR textures.
- **Floating Animations**: Sine-wave drift and rotation applied to tiles.
- **Special Effects**: Gravity mode and Explode mode implemented.
